# 🕵️‍♂️ Competitor Intel — AI-Powered Intelligence Dossier

An advanced, dossier-themed **Competitor Intelligence & Market Analysis Tool** that leverages **Google Gemini AI** to generate deep competitive insights. Users can input their company along with up to 3 competitors to receive a structured, analytical intelligence report featuring executive summaries, threat assessments, and strategic recommendation memos.

🌐 **Live Demo:** [Insert Your Render Link Here](https://onrender.com)

---

## 🚀 Key Features (7-Phase Architecture)

- **🕵️ Dossier-Themed UI:** A high-fidelity, secret-agent/investigator themed interface complete with feature tabs and professional copy.
- **📊 Multi-Competitor Intake Form:** Robustly handles input for your company and up to 3 target competitors with strict domain validation.
- **📡 Real-Time Progress Screen:** Features an immersive radar animation synced with genuine, step-by-step backend stage status logs (no fake loading theater).
- **📋 Full Intelligence Report:** 
  - **Executive Summary:** High-level overview of the competitive landscape.
  - **Profile Cards:** Individual competitor breakdowns featuring custom **Threat Stamps**.
  - **Comparison Matrix:** A structured grid comparing key metrics side-by-side.
  - **Recommendations Memo:** Actionable strategic advice generated by AI.
- **📋 Smart Clipboard:** A "Copy briefing as text" button for seamless, one-click report sharing.
- **🛑 Advanced Error Handling:** Dedicated "The trail went cold" screen with precise error detail boxes and an instant "Retry" button that re-runs the investigation without losing form data.
- **🤖 Gemini AI Integration:** Fully wired `/api/analyze` backend endpoint built to communicate with Google Gemini API for deep qualitative synthesis.

## 🛠️ Tech Stack

- **Frontend:** React.js, Tailwind CSS (for the Dossier/Cyberpunk cyber-detective aesthetic), Lucide Icons, Framer Motion (Radar Animation).
- **Backend:** Node.js, Express.js (Modular architecture with `/api/analyze` endpoint).
- **AI Engine:** Google Gemini API (Structured JSON prompt engineering).
- **Deployment:** Render (`onrender.com`).
- **Version Control:** Git & GitHub (Clean 7-phase commit history).

---

## ⚙️ AI Architecture & Prompt Engineering

The system sends a carefully structured, multi-variable prompt to the **Google Gemini API**. The model processes the metadata of the subject company and its competitors, returning a strictly formatted **JSON object**. 

This allows the frontend to parse the AI's complex qualitative analysis dynamically into visual UI elements like the **Comparison Matrix** and **Threat Assessment Stamps**.

## 🛠️ Local Setup & Installation

To run this project locally, follow these steps:

### 1. Clone the Repository
```bash
git clone https://github.com
cd YOUR_REPO_NAME
```

### 2. Install Dependencies
For Frontend:
```bash
cd client
npm install
```
For Backend:
```bash
cd ../server
npm install
```

### 3. Environment Variables
Create a `.env` file in your root backend folder and add your verified Gemini API key:
```env
PORT=5000
GEMINI_API_KEY=your_actual_gemini_api_key_here
NODE_ENV=production
```
*(Note: The codebase contains a rock-solid mock-data fallback for seamless demonstrations and recording sessions without API rate-limit interruptions).*

### 4. Start the Application
```bash
# Start backend server
cd server
npm start

# Start frontend development server
cd ../client
npm run dev
```
